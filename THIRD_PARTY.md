# Third-party provenance

`starter-repo/` contains selected public source and documentation vendored without changes from https://github.com/metrica-sports/more-than-a-hack-2027 at commit `f8f2629ff1e0985f81d7e59d8413678514ee1530`. The original MIT notice is retained in `starter-repo/LICENSE` and applies to those upstream files. Selection: root Markdown/CFF/licence/requirements plus Python modules under starter/ and evaluation/. Public ground-truth CSVs, baseline prediction CSVs, notebooks, data and upstream Git metadata are intentionally omitted from this cloud package. Retrieve public documentation from the upstream link if needed; do not fetch the five-minute labels for model improvement.

`work/learned-evaluation/model.pkl` was trained locally using public Metrica Sports Sample Game 1 event/tracking data. Public external dataset source: https://github.com/metrica-sports/sample-data at commit `e706dd506b360d69d9d123d5b8026e7294b13996`. Authors request attribution. No standalone redistribution licence was supplied, so raw datasets and event-definition extracts are not bundled or relicensed. External data hashes and training split are recorded in work/hybrid-evaluation/provenance.json and the experiment registrations.

Nilay's original work is licensed MIT (root `LICENSE`, chosen 3 November 2026). Competition match assets are separately restricted, absent from this repository and never covered by the organiser's code licence.

`v2/` reads the IDSSE/DFL open dataset: Bassek, M., Rein, R., Weber, H. & Memmert, D. (2025), "An integrated dataset of spatiotemporal and event data in elite soccer", Scientific Data 12:195; figshare doi 10.6084/m9.figshare.28196177.v1, licence CC BY 4.0. Raw files are fetched into ignored `external/idsse/` only (see `README.md`, "Verify the model from public data") and are not bundled. Any derived public material must carry this attribution.

`v3/` evaluation reads SkillCorner open data (https://github.com/SkillCorner/opendata, commit 4340d274572876239c154c90bc507a9b3250a656), MIT licence, Copyright (c) 2020 SkillCorner. Raw files stay in ignored `external/`; SkillCorner asks users to credit them.

`v12/final.pt` (the v12 network, EXPERIMENT-22) was trained on DFL/IDSSE (CC BY 4.0), SkillCorner open data (MIT) and Metrica Sports Sample Games 1 to 3 (same source and commit as above; authors request attribution). Metrica training labels come from our own fixed event rule (`exp22/metrica.py`). No raw data is bundled.

PFF FC World Cup 2022 tracking and event data (64 matches) was released free by PFF FC (https://www.blog.fc.pff.com/blog/pff-fc-release-2022-world-cup-data); we obtained it through PFF FC's request form on 10 November 2026, subject to PFF FC's Terms of Use, and used it only to test models. It never trained `v12/final.pt`; no PFF data or per-frame output is included, and results files report aggregates only.

The dropped video experiment (EXPERIMENT-17) used the WASB ball detector (Tarashima, S. et al. (2023), BMVC 2023, arXiv 2311.05237; code https://github.com/nttcom/WASB-SBDT, MIT licence) with ISSIA-CNR weights under their non-commercial research terms. Its code and weights are not in this repository and nothing from it is in the submission.

Ideas tested from other public entries to this challenge, ideas only and no code copied (all code here is our own): SAM-Analytics-2027 (touch-sequence and last-seen-ball features and past-only and future-only summaries in EXPERIMENT-26, and the decoder starting point in EXPERIMENT-25; neither adopted), nathangalung/BYTZ (averaging predictions over mirrored copies of the tracking; EXPERIMENT-27, adopted in v13), OsamaQ05 (control-event definition; EXPERIMENT-26), and alhassanradwan and MikolajEkiert (their public repositories were read when designing EXPERIMENT-25, not adopted).
